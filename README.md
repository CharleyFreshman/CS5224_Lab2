# CS5224 Lab 2 — Twitter Follower/Followee Analysis Pipeline

**Twitter dataset → GCS → Dataproc (PySpark) → FastAPI back-end → HTML/JS front-end**

## Repository layout

```text
.
├── analysis/
│   ├── twitter_analysis.py   # PySpark job: parse → dedupe → count → full outer join → CSV
│   ├── smoke_local.py        # Local pure-Python mirror of the Spark logic (tests + sample)
│   └── day1_smoke_test.py    # Dataproc smoke job (data validity check)
├── backend/
│   ├── main.py               # FastAPI: GET /api/users/{id}, hosts the front-end
│   └── data/part-*.csv       # Spark output CSV (synced from GCS)
├── frontend/
│   └── index.html            # fetch() → renders "UserID has N of followers/followees"
└── README.md
```

## Prerequisites

- Python 3.10+ / `pip install fastapi uvicorn`
- For GCS & Dataproc steps: `gcloud` CLI authenticated to a GCP project with the bucket `cs5224-twitter-ssf`
- Commands use bash line-continuations (`\`). On Windows PowerShell, run them in **Git Bash** (or join each command into a single line)

## 1. View the analysis results (GCS)

```bash
gcloud storage cat gs://cs5224-twitter-ssf/outputs/twitter_summary/part-00003-f9882b24-97c8-4bf7-b4f9-436adb6bded0-c000.txt
gcloud storage cat gs://cs5224-twitter-ssf/outputs/twitter_stats/part-00000-1e9b23b6-d2c7-48ee-a9e7-71fa501efbb9-c000.csv
```

The first is the run summary (cleaning metrics + target users); the second is per-user `user_id,followers,followees` (81,306 rows). Part filenames are generated by Spark — after re-running the job, list current names with `gcloud storage ls --recursive gs://cs5224-twitter-ssf/outputs/`.

## 2. Run the back-end and front-end

From the repository root:

```bash
gcloud storage rsync gs://cs5224-twitter-ssf/outputs/twitter_stats backend/data --exclude "_SUCCESS"
cd backend
uvicorn main:app --host 127.0.0.1 --port 8000
```

Open http://127.0.0.1:8000/ — the page fetches both required users automatically; a search box queries any of the 81,306 users.

### Verify the API (open a second PowerShell window)

```powershell
curl.exe http://127.0.0.1:8000/api/users/214328887
curl.exe http://127.0.0.1:8000/api/users/107830991
```

Expected: `{"user_id":"214328887","followers":180,"followees":214}` and `{"user_id":"107830991","followers":180,"followees":157}` (unknown IDs return 404).

## 3. Re-run the analysis (Dataproc / PySpark)

```bash
gcloud dataproc clusters create cs5224-day3-final --region=asia-southeast1 \
  --image-version=2.2 --num-workers=2 \
  --master-machine-type=e2-standard-2 --worker-machine-type=e2-standard-2 \
  --master-boot-disk-size=50 --worker-boot-disk-size=50 --no-address

gcloud storage cp analysis/twitter_analysis.py gs://cs5224-twitter-ssf/scripts/

# args: <input> <output_csv> <summary> [ids]
gcloud dataproc jobs submit pyspark gs://cs5224-twitter-ssf/scripts/twitter_analysis.py \
  --cluster=cs5224-day3-final --region=asia-southeast1 \
  --properties spark:spark.sql.shuffle.partitions=16,spark:spark.default.parallelism=16 \
  -- gs://cs5224-twitter-ssf/raw/twitter_combined.txt \
     gs://cs5224-twitter-ssf/outputs/twitter_stats \
     gs://cs5224-twitter-ssf/outputs/twitter_summary \
     214328887,107830991

gcloud dataproc clusters delete cs5224-day3-final --quiet
```
